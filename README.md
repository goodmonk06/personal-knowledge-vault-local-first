# Knowledge Vault - ローカルファースト個人ナレッジボルト

プライバシーとセキュリティを重視した、ローカルファーストの個人ナレッジ管理アプリケーションです。

## 特徴

- **完全ローカル保存**: すべてのデータはローカルのSQLiteデータベースに保存されます
- **暗号化**: データベースファイルを暗号化してエクスポート可能
- **タグ管理**: ノートにタグを付けて整理
- **全文検索**: タイトルと本文から簡易全文検索
- **軽量**: Tauriベースで軽量かつ高速
- **クロスプラットフォーム**: Windows、macOS、Linux対応

## アーキテクチャ

- **フレームワーク**: Tauri 2.x（Rustベース）
- **フロントエンド**: React + TypeScript + Vite
- **データストア**: SQLite（ローカル）
- **暗号化**: AES-256-GCM + Argon2

## ユースケース: 外部ストレージへのバックアップ

このアプリケーションは「**ローカルファースト**」設計を採用しています。データは外部クラウドサービスに送信されず、完全にあなたのデバイス上に保存されます。

### バックアップワークフロー

1. **日常の使用**
   - すべてのノートはローカルのSQLiteデータベースに保存されます
   - データベースは`~/.local/share/knowledge-vault/`（Linux）などのアプリデータディレクトリに配置
   - インターネット接続は不要です

2. **暗号化アーカイブのエクスポート**
   - アプリ内の「エクスポート」ボタンをクリック
   - パスワードを設定（このパスワードでアーカイブが暗号化されます）
   - `.enc`ファイルとして保存されます
   - このファイルには以下が含まれます：
     - データベース全体（すべてのノートとタグ）
     - メタデータ（バージョン、エクスポート日時）

3. **外部ストレージへの保存**
   - エクスポートした`.enc`ファイルを以下に保存できます：
     - 外付けHDD/SSD
     - USBメモリ
     - NAS（Network Attached Storage）
     - プライベートクラウドストレージ（自己ホストNextcloud等）
   - ファイルは暗号化されているため、パスワードなしでは読み取り不可

4. **復元**（将来実装予定）
   - バックアップファイルをインポート
   - パスワードを入力して復号化
   - データベースを復元

### なぜローカルファーストなのか？

- **プライバシー**: あなたのデータは第三者に共有されません
- **所有権**: データは完全にあなたのものです
- **オフライン動作**: インターネット接続不要
- **セキュリティ**: 暗号化により物理的な保管も安全
- **ベンダーロックインなし**: データ形式はオープン（SQLite）

### セキュリティのベストプラクティス

- **強力なパスワード**: エクスポート時は12文字以上の複雑なパスワードを使用
- **複数バックアップ**: 3-2-1ルール（3コピー、2種類のメディア、1つはオフサイト）
- **定期的なエクスポート**: 週次または月次でバックアップ
- **物理セキュリティ**: バックアップメディアは安全な場所に保管

## 開発環境のセットアップ

### 前提条件

- Node.js 18+
- Rust 1.70+
- Tauri依存関係（[Tauri Prerequisites](https://tauri.app/start/prerequisites/)を参照）

### インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run tauri dev

# プロダクションビルド
npm run tauri build
```

## 使い方

1. **ノートの作成**
   - 「+ 新規ノート」ボタンをクリック
   - タイトル、内容、タグ（カンマ区切り）を入力
   - 「作成」をクリック

2. **ノートの編集**
   - サイドバーからノートを選択
   - 「編集」ボタンをクリック
   - 内容を変更して「保存」

3. **検索**
   - ヘッダーの検索ボックスにキーワードを入力
   - Enterキーまたは「検索」ボタンをクリック
   - タイトルと内容から部分一致で検索

4. **エクスポート**
   - 「エクスポート」ボタンをクリック
   - パスワードを入力
   - 保存先を選択

- **React 19**: UIフレームワーク
- **TypeScript**: 型安全性
- **Vite**: ビルドツール
